## Appris

- Ce que je sais ce soir :
  - Le matériel nécessaire à la réalisation d'une **station météo**, notamment les capteurs, la carte électronique, les fils de connexion et les autres composants nécessaires.
  - **I2C** est un protocole de communication qui permet à plusieurs composants électroniques de communiquer entre eux en utilisant généralement deux lignes :
    - **SDA** : ligne utilisée pour transmettre les données.
    - **SCL** : ligne utilisée pour synchroniser la communication.
  - **VCC (+)** correspond à la borne positive de l'alimentation électrique d'un composant.
  - **GND (-)** correspond à la masse ou à la borne négative du circuit.
  - `while True` permet de créer une **boucle infinie** en Python. Les instructions placées à l'intérieur de cette boucle sont exécutées continuellement tant que le programme fonctionne.
  - Une boucle `while True` est particulièrement utile pour une station météo, car elle permet de relever régulièrement les données des capteurs sans arrêter le programme.
  - J'ai également compris l'importance de bien connecter les composants entre eux afin d'éviter les erreurs de fonctionnement.
